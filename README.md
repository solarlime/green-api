# Green API

Интерфейс для обмена сообщениями Telegram, построенный на React, TypeScript и Vite. Использует Green API для интеграции с Telegram.

## Что может:
- Отправка и получение сообщений
- Отображение чатов

## Онлайн-демо

Попробуйте приложение онлайн: [green-api-solarlime.vercel.app](https://green-api-solarlime.vercel.app)

## Локальная разработка

### Установка

```bash
npm install
```

### Запуск сервера разработки

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5173`

### Сборка для продакшена

```bash
npm run build
```

### Проверка кода

```bash
npm run lint
```

### Форматирование

```bash
npm run format
```

## Технологии

- **React 19** - UI библиотека
- **TypeScript** - Типизация
- **Vite** - Сборщик и dev сервер
- **MobX** - Управление состоянием
- **React Router** - Маршрутизация
- **Phosphor Icons** - Библиотека иконок
